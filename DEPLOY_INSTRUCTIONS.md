# 🌟 How to Show Your Animated Dashboard on Your Public GitHub Profile

To make this animated dashboard appear at the very top of your public profile at **`https://github.com/poharekulbhushan2006-code`**, GitHub uses a special feature called the **Profile README**.

---

## ⚡ 3-Step Setup (Takes Under 2 Minutes)

### Step 1: Create Your Profile Repository on GitHub
1. Open your browser and go to: **[https://github.com/new](https://github.com/new)**
2. In the **Repository name** field, type your exact GitHub username:
   ```
   poharekulbhushan2006-code
   ```
   *(GitHub will show a green banner: "✨ You found a secret! poharekulbhushan2006-code is a special repository...")*
3. Make sure **Public** is selected.
4. Click **Create repository** (do NOT check "Add a README file" if you want to push from here, or overwrite it).

---

### Step 2: Push the Files
In PowerShell or Command Prompt, run:

```powershell
cd "d:\projects\project 1\operating system\github_profile_package"
git init
git branch -M main
git add .
git commit -m "feat: launch animated public GitHub profile dashboard"
git remote add origin https://github.com/poharekulbhushan2006-code/poharekulbhushan2006-code.git
git push -u origin main --force
```

*(Or simply double-click [`deploy.bat`](file:///d:/projects/project%201/operating%20system/github_profile_package/deploy.bat).)*

---

### Step 3: Enable the Animated Contribution Snake (GitHub Actions)
1. Go to your repository settings:
   `https://github.com/poharekulbhushan2006-code/poharekulbhushan2006-code/settings/actions`
2. Under **Workflow permissions**, select **Read and write permissions**.
3. Click **Save**.
4. Go to the **Actions** tab on GitHub, click **Generate Contribution Snake Animation**, and click **Run workflow**.

---
